# معجم مصطلحات React

## React Arabic Glossary — من المصطلح إلى الفهم الهندسي

مشروع مفتوح المصدر يهدف إلى بناء مرجع تقني باللغة العربية لفهم مصطلحات ومفاهيم مكتبة **React**، بدءاً من الأساسيات وصولاً إلى المفاهيم المتقدمة وآليات عمل React.

## 🎯 هدف المشروع

يهدف هذا المعجم إلى مساعدة المطور العربي على تجاوز الحفظ السطحي للمصطلحات التقنية، والوصول إلى فهم حقيقي للمفاهيم التي يستخدمها يومياً عند تطوير تطبيقات React.

نؤمن أن فهم المصطلح لا يقتصر على معرفة ترجمته، بل يتطلب فهم معناه التقني، وكيفية عمله، ومتى يُستخدم، وما علاقته بالمفاهيم الأخرى.

## 📚 منهجية الشرح

سيُشرح كل مصطلح وفق منهجية موحدة تشمل:

1. **المصطلح الأصلي:** اسمه باللغة الإنجليزية.
2. **المقابل العربي:** ترجمة عربية دقيقة ومناسبة للسياق التقني.
3. **التعريف العلمي:** تعريف واضح للمفهوم في سياق React.
4. **الشرح المبسط:** تقريب المفهوم إلى ذهن القارئ دون الإخلال بدقته.
5. **التفسير التقني:** توضيح آلية العمل والتفاصيل المهمة.
6. **أمثلة برمجية:** أمثلة عملية تساعد على فهم الاستخدام.
7. **المفاهيم المرتبطة:** المصطلحات التي تتكامل معه أو تختلف عنه.
8. **الأخطاء الشائعة:** تصحيح التصورات غير الدقيقة.
9. **الخلاصة:** الفكرة الأساسية التي ينبغي للقارئ الاحتفاظ بها.
10. **المراجع:** روابط المصادر التقنية الموثوقة.

## 📖 الفئة المستهدفة

- مطورو JavaScript الذين يرغبون في فهم React بعمق.
- مطورو React الذين يريدون ترسيخ معرفتهم التقنية.
- المطورون العرب الذين يجدون صعوبة في فهم المصطلحات الإنجليزية.
- كل من يسعى إلى تطوير تفكيره الهندسي وفهم الأنظمة البرمجية.

## 🔬 معايير الدقة العلمية

- الاعتماد على وثائق React الرسمية كمصدر أساسي.
- التمييز بين واجهات React العامة والتفاصيل الداخلية لتنفيذ المكتبة.
- توضيح الاختلافات المرتبطة بإصدارات React عند الحاجة.
- عدم تقديم المصطلحات التفسيرية أو الشائعة باعتبارها مفاهيم رسمية دون توضيح.
- كتابة شروحات أصلية بدلاً من نسخ محتوى المصادر.
